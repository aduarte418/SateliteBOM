# Documento analisis.md

Este archivo md contiene la documentación y justificación de los aspectos técnicos de la actividad.

1. **Diferencias entre tipos de objetos**

El objeto window es el elemento principal del BOM, que permite interactuar con el navegador y gestionar la ventana, siendo el puente entre el código y el navegador, aunque no permita interactuar directamente con el contenido de la página, que correspondería al DOM.

Es un objeto referente a la ventana del navegador, actuando en el ámbito global de éste.
Su diferencia con un objeto nativo de Javascript como Math, es que éste está predefinido en el lenguaje y es estático, no dependiendo del navegador para su funcionamiento. 



2. **Identificación de categorías de objetos**

window.open() --> Objeto del BOM
    
parseFloat()  --> Objeto nativo de Javascript
    
Math.floor()  --> Objeto nativo de Javascript
    
navigator.userAgent  --> Objeto del BOM
