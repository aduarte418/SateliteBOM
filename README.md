# SateliteBOM
Repo para la Actividad El Satélite Del BOM de Desarrollo Entorno Cliente

La actividad contiene los archivos HTML con sus respectivos script JS, suponiendo index.html la ventana principal y satelite.html la ventana satélite. 

El archivo analisis.md contiene la documentación y justificación de esta actividad, identificando los objetos definidos y utilizados.

El proyecto será desplegado en las Github Pages de este repositorio.
